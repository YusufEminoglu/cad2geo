1. Installation & Quickstart

cad2geo is a lightweight, pure-Python library designed to inspect Netcad NCZ (compressed archive) and NCA (raw binary drawing stream) files and convert CAD geometries into GeoJSON without requiring QGIS, GDAL, or proprietary CAD runtimes.

Standard Installation

pip install cad2geo

High-Level Python API

from cad2geo import inspect_source, parse_netcad, write_geojson

# 1. Fast O(1) Layer Catalog Inspection (Without decoding geometry)
layers = inspect_source("imar_plani.ncz")
for layer in layers:
    print(f"Layer #{layer.layer_code}: {layer.layer_name} ({layer.record_count} entities)")

# 2. Selective Decoding (Decode only zoning boundaries: Layer 1, 3, 7)
result = parse_netcad("imar_plani.ncz", target_layers=[1, 3, 7])
print(f"Decoded {len(result.entities)} entities across {len(result.layers)} layers.")

# 3. Export to Standard GeoJSON FeatureCollection
write_geojson(result.entities, "imar_plani_zoning.geojson")

Command Line Interface (CLI)

# Inspect drawing layers and summary metadata
cad2geo inspect imar_plani.ncz

# Output layer summary as machine-readable JSON
cad2geo inspect imar_plani.ncz --json

# Convert entire NCZ drawing to GeoJSON
cad2geo convert imar_plani.ncz imar_plani.geojson

# Selective conversion of specific layer IDs with formatted JSON output
cad2geo convert imar_plani.ncz parcel_boundaries.geojson --layers 1,3,7 --pretty

2. Binary Architecture & NCZ/NCA Specifications

Netcad NCZ files are zlib-compressed binary archives wrapping an NCA CAD entity stream. cad2geo implements a custom stream parser that decodes binary blocks directly through Python's standard struct library:

Binary Layout Pipeline:
.NCZ File $\rightarrow$ Zlib Decompression $\rightarrow$ NCA Binary Stream $\rightarrow$ Header Block Scanner (O(1)) $\rightarrow$ Entity Decoders $\rightarrow$ Dataclass Model $\rightarrow$ GeoJSON FeatureCollection

O(1) Layer Catalog Scanning

In large municipal urban plans (100MB+ NCZ drawings containing over 500,000 entities), fully reconstructing polygon topology just to see what layers exist is computationally wasteful. cad2geo parses the binary layer definition table located in the file header, extracting layer names, display colors, line styles, and entity counts in under 5 milliseconds.

Selective Layer Filtering

By supplying a target_layers filter list, the binary parser skips unneeded byte offsets directly in the stream, saving up to 90% memory allocation and 10x CPU time during automated GIS batch ingestion pipelines.

3. CAD to GIS Entity Mapping & Curve Discretization

Netcad CAD entities are mapped to standard OGC/GeoJSON geometries with full attribute preservation:

Netcad CAD Entity Internal Binary Type OGC / GeoJSON Target Extracted Properties
Point / Nokta TYPE_POINT (0x01) Point Point name, point code, elevation ($Z$), layer
Line / Çizgi TYPE_LINE (0x02) LineString Length, line style, color, layer code
Polyline / Çoklu Doğru TYPE_PLINE (0x03) LineString / Polygon Closed flag, vertices, perimeter, area
Arc / Yay TYPE_ARC (0x04) LineString (Tessellated) Center, radius, start angle, end angle
Circle / Çember TYPE_CIRCLE (0x05) Polygon (Tessellated) Center, radius, circumference, area
Text / Yazı TYPE_TEXT (0x06) Point Text string, height, rotation angle, justification
Polygon / Alan TYPE_POLYGON (0x07) Polygon / MultiPolygon Parcel number (Ada/Parsel), zoning attribute table

Mathematical Curve Discretization

Circular arcs and curves in Netcad CAD are discretized into piecewise linear segments according to the maximum allowable sagitta chord tolerance $\delta$:

$$\text{Chord Angle Step: } \Delta\theta = 2 \arccos\left(1 - \frac{\delta}{R}\right)$$ $$\text{Number of Vertices: } N = \left\lceil \frac{\theta_{sweep}}{\Delta\theta} \right\rceil$$

4. Python API Reference

cad2geo.inspect_source(source, encoding="windows-1254") -> list[LayerInfo]

Scans the layer catalog of an NCZ/NCA file without decompressing full geometric coordinates.

from cad2geo import inspect_source

layers = inspect_source("cadastre.ncz")
# Returns: [LayerInfo(layer_code=1, layer_name='PARSEL_SINIRI', record_count=1420), ...]

cad2geo.parse_netcad(source, target_layers=None, chord_tolerance=0.05) -> ParseResult

Decompresses and decodes the complete drawing or filtered layers into structured dataclass entities.

from cad2geo import parse_netcad

result = parse_netcad("master_plan.ncz", target_layers=[1, 2])
for entity in result.entities:
    print(entity.geometry_type, entity.layer_code, entity.coordinates)

cad2geo.write_geojson(entities, output_path, crs="EPSG:4326") -> None

Serializes entity dataclasses into a valid OGC GeoJSON FeatureCollection file.

from cad2geo import parse_netcad, write_geojson

result = parse_netcad("zoning.ncz")
write_geojson(result.entities, "zoning.geojson")
