# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-25
### Added
- Initial `cad2geo` SDK package.
- Added pure-Python Netcad NCZ/NCA parser and lazy layer catalog.
- Added stable public dataclasses for Netcad entities and parse results.
- Added GeoJSON export helpers.
- Added `cad2geo inspect` and `cad2geo convert` CLI commands.
- Added parser, reader, GeoJSON, and CLI tests built on synthetic NCZ fixtures.
